Comment jouer:

Le but est d'être le premier joueur à se débarrasser de toutes ses cartes, en les posant dans des suites, sur la table de jeu.

Un joueur peut former pendant son tour:

  • une suite de minimum 3 cartes consécutives de la même famille (ex: A♣, 2♣, 3♣) (10♣, V♣, D♣, R♣)
  • ou minimum 3 de même valeur mais de familles différentes (ex: D♦ D♠ D♥)

On peut aussi ajouter ses cartes dans une suite déjà sur la table si elles respectent la combinaison (ex: D♣ → D♦ D♠ D♥) (4♣ → A♣, 2♣, 3♣)

Chaque tour, il est possible de piocher soit une carte aléatoire dans la pioche, ou une carte défaussée par le joueur précédent.

Il faut ensuite défausser une carte pour marquer la fin de son tour

Pas de système de points minimum pour poser une suite ici dans cette version du rami

Contrôles:

Desktop (Clavier):

  • S : sélectionner/déselectionner une carte
  • Z : ajouter une suite avec les cartes sélectionnées
  • A : ajouter une carte à une suite préexistante
  • D : défausser une carte (fin de tour)

Clique gauche sur une suite pour la sélectionner/déselectionner

Mobile (Tactile):

  • Appuyer sur une carte : la marquer comme cible avant d'appuyer sur les boutons souhaités
  • Appuyer sur une suite : la sélectionner pour y ajouter des cartes

Glisser avec son doigt la barre de carte vers la droite pour voir les autres cartes et piocher

Difficulté Bots:

Bot Facile:

  • Temps de réflexion : 2 secondes
  • Probabilité de créer une suite : 50%
  • Probabilité d'ajouter à une suite existante : 30%
  • Probabilité de défausse intelligente* : 20%

Bot Moyen:

  • Temps de réflexion : 1.5 secondes
  • Probabilité de créer une suite : 75%
  • Probabilité d'ajouter à une suite existante : 60%
  • Probabilité de défausse intelligente* : 50%

Bot Difficile:

  • Temps de réflexion : 1 seconde
  • Probabilité de créer une suite : 95%
  • Probabilité d'ajouter à une suite existante : 90%
  • Probabilité de défausse intelligente* : 85%

Bot Réaliste:

  • Temps de réflexion : 0.4 secondes
  • Probabilité de créer une suite : 100%
  • Probabilité d'ajouter à une suite existante : 100%
  • Probabilité de défausse intelligente* : 100%

*La défausse intelligente permet au bot de se débarrasser de la carte la moins utile, sinon le bot défausse aléatoirement l'autre partie du temps
